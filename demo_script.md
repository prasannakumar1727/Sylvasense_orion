# 3-Minute Demo Script (for the linked video / live defense)

1. **Problem (20s):** ground-based canopy surveys don't scale; carbon-claim
   verification is slow and unrepeatable.
2. **Select AOI (20s):** pick a cached demo region on the map — no live network
   dependency during judging.
3. **Run pipeline (40s):** show NDVI → canopy density → change-detection output
   (the before/after visual from the deck) → AGB range with confidence flag.
4. **Explain the honesty layer (40s):** point out the cited model, the
   uncertainty range, and the confidence flag — this is the differentiator,
   say it explicitly.
5. **Sample output contract (20s):** show the JSON response — signals this is
   a real API, not a notebook demo.
6. **Impact (20s):** who uses this and why it's repeatable, not a one-off.
7. **Close (20s):** what's MVP vs. roadmap — be explicit about the line.

Keep this same script for the actual submission video; consistency between the
deck, the video, and the live defense is itself a credibility signal.
